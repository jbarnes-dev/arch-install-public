# Arch Linux desktop installer

Personal, opinionated scripts for setting up an X11/i3 Arch Linux desktop.
Configuration files are generated by shell heredocs, so the setup can be
reviewed and customized in one place without maintaining a second dotfiles
tree.

## Usage

Start from an installed, fully booted Arch Linux system with a regular user
that has `sudo` access:

```sh
git clone <repository-url> arch-install
cd arch-install
./install.sh
```

Do not run the installer as root. It invokes `sudo` only for pacman and
systemd operations; AUR packages and home-directory configuration run as the
logged-in user.

The installer:

1. performs a full system upgrade and installs official packages;
2. bootstraps `yay` from the AUR when it is not already installed;
3. installs the selected AUR packages;
4. generates the i3, Polybar, Picom, Rofi, shell, Vim, GTK, and X11 configs;
5. enables and starts NetworkManager.

Existing top-level shell/Vim/X11 configuration files are copied to a
`.pre-arch-install` backup before they are replaced. Pictures are copied only
when a file with the same name does not already exist.

Package selections live in
[`scripts/install-packages.sh`](scripts/install-packages.sh) and
[`scripts/install-aur.sh`](scripts/install-aur.sh). User configuration lives
in [`scripts/configure-user.sh`](scripts/configure-user.sh).

This is a personal setup rather than a general-purpose Arch installer. Review
the package lists and hardware-specific settings (especially battery and
thermal-zone names) before running it.
